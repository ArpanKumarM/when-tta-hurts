# paper/

## Phase 0 status

Empty. No manuscript has been started. A 4–6 page technical report /
workshop-style writeup is a *possible* downstream deliverable (see
`docs/research_plan.md`), contingent on Phase 1+ producing results that
support a defensible claim.

## Ground rules for when writing starts

- Every claim in the manuscript must trace to a specific artifact in
  `results/` (raw predictions + a script that computes the reported number).
- No claim of novelty without the literature comparison in
  `docs/literature_review.md` being current and re-checked.
- No clinical-use language of any kind (see `docs/claims_and_risks.md`).
- Confirmatory vs. exploratory results must be labeled as such, per
  `docs/statistical_analysis_plan.md`.
